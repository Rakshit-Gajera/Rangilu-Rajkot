# Rangilu Rajkot

A free-roam, open-world **browser game** set in a 1:1 recreation of Rajkot, Gujarat, built from open map data.
Walk, ride and drive anywhere in the real city — every street, ring road, lake and landmark in its true place.

> Status: **Phase 1 — vertical slice.** Walk and ride a scooter around Race Course, Jubilee Garden and the old-city bazaars. See [PROGRESS.md](PROGRESS.md).

## How it works

- **The bake (Python, `pipeline/`)** turns OpenStreetMap, Overture buildings and Copernicus elevation into a compact database of *facts*: building outlines and heights, roads, water, trees, landmarks.
- **The game (TypeScript + Three.js, `game/`)** generates the 3D city from those facts in Web Workers, seeded per object so the city looks the same every run.

## Playing (Windows)

```bash
cd game
npm install
npm run dev
```

Open http://localhost:5173. Click the game to look around with the mouse.
**WASD** move · **Shift** sprint · **Space** jump / brake · **E** get on/off the scooter · **H** horn · **T** +1 hour · **C** camera · **R** reset scooter · **F3** performance stats.

The world package (`world/`) is generated by the bake below; run it once before playing.

## Running the bake (Windows)

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -e pipeline[dev]
.venv/Scripts/python -m rajkot_bake fetch     # download raw data into data/raw (~300 MB)
.venv/Scripts/python -m rajkot_bake all       # every stage, in order (~6 min)
```
